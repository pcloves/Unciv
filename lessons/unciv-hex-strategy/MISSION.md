# Mission: 从 Unciv 到 Godot：六边形策略游戏系统

## Why

通过精读 Unciv 的真实源码，掌握六边形策略游戏中地图、经济与其他系统的组织和联动方式，为未来使用 Godot 4 C# 设计武侠门派经营、古代中国城池建设或武侠探险游戏提供可迁移的工程判断。

## Success looks like

- 能从界面操作追踪到规则判定、状态变更、回合结算及界面更新，并指出实际源码位置。
- 能解释六边形坐标、地图存储、分阶段生成、出生点与资源分配、寻路及显示的职责。
- 能追踪地块产出、人口分配、粮食增长、建造生产、文明收支和资源贸易的因果链。
- 能给定一个小场景，预测结算结果，并用源码或现有测试验证、修正自己的预测。
- 能为三类目标游戏比较可复用思想与需要改造的规则，说明 Godot 数据与节点职责及不同时间机制的取舍。

## Constraints

- Java 熟练、Kotlin 约半年、Godot 4 C# 约两年，主要做 2D 地图和 UI。
- 每课约 40～60 分钟，以理解 Unciv 为主；地图生成和经济系统设连续专题。
- 先整体后局部，以代码及注释为主；中文宽屏 HTML，配套速查和检索反馈。
- 尚未确定目标游戏主案例及时间机制，课程保持开放并在后期比较。

## Out of scope

- 当前课程不安排同步开发 Godot 原型；Godot 用于概念对照与设计推演。
